Öğrenme Yolları

Sıralı, referanslı öğrenme rotaları. Türkçe kaynaklar önceliklidir, İngilizceler "sonra izle".

Şu an yalnızca bu cihazda saklanıyor — cihazlar arası senkron için kurulum (SQL)

Supabase projende SQL Editor'da aşağıdakini bir kez çalıştır; sayfayı yenileyince otomatik senkronlanır.

create table if not exists learning_state (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz default now()
);
alter table learning_state enable row level security;
create policy "own learning_state" on learning_state
  for all using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
